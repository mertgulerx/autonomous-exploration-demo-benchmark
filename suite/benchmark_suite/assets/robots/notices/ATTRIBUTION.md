# Robot preview assets

These PNG previews were rendered from the robot descriptions used by the benchmark.
They retain the native visual geometry and materials. Studio lighting, camera
position and framing were added for the campaign selector. Source meshes are not
bundled with the GUI. The model authors' licenses and notices continue to apply.
